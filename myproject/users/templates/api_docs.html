Credit Card Payment System API Documentation

Authentication APIs

1. Register User

Method: POST

URL: /api/register/

{
    "username": "saimanohar",
    "email": "saimanohar@example.com",
    "first_name": "Sai",
    "last_name": "manohar",
    "password": "Password123"
}

2. Login

Method: POST

URL: /api/login/

{
    "username": "saimanohar",
    "password": "Password123"
}

Returns a JWT access token.

3. Logout

Method: POST

URL: /api/logout/

Authentication: Bearer Token

Card APIs

4. Add Card

Method: POST

URL: /api/add_card/

Authentication: Bearer Token

5. View Cards

Method: GET

URL: /api/view_card/

Authentication: Bearer Token

6. Delete Card

Method: DELETE

URL: /api/Delete_card/<card_id>/

Authentication: Bearer Token

Transaction APIs

7. Transaction History

Method: GET

URL: /api/transactions/

Authentication: Bearer Token

Supported filters:

  • status
  • amount
  • date

Example:

/api/transactions/?status=SUCCESS&amount=500&date=2026-09-29

8. Export Transactions

Method: GET

URL: /api/transactions/export/

Authentication: Admin Bearer Token

Testing API

9. Protected Test

Method: GET

URL: /api/protected_test/

Authentication: Bearer Token
